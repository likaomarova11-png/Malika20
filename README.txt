MAELYN BEAUTY ATELIER — полностью автономная версия.

Как открыть:
1. Распакуйте ZIP.
2. Откройте файл index.html двойным кликом.
3. Интернет не требуется.

Внешние сервисы:
- нет;
- Google Fonts не используются;
- CDN не используется;
- API не используется;
- база данных не используется;
- подписка не нужна.

Форма записи работает только локально: она показывает подтверждение и ничего не отправляет.
Чтобы изменить название, цены, адрес и телефон — редактируйте index.html.
Чтобы изменить дизайн — редактируйте style.css.
